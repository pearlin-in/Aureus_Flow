# Aureus Flow

A client-side personal finance management dashboard built to track multi-fund savings, monitor category-level spending, and manage filterable transaction histories with dynamic alerts.

## Features

* **Multi-Fund Savings Tracking:** Monitor money allocated across different financial goals and savings categories.
* **Categorized Spending Monitors:** Keep tabs on cash flow across various expense categories.
* **Filterable Transaction Ledger:** Search, sort, and filter historical transactions quickly.
* **Dynamic Alerts:** Real-time visual alerts powered by jQuery triggered when budget thresholds are breached.

## Tech Stack

* **Frontend:** React, HTML5, CSS
* **Utilities:** jQuery

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/your-username/aureus-flow.git

```


2. Navigate into the project directory:
```bash
cd aureus-flow

```


3. Install dependencies:
```bash
npm install

```


4. Run the development server:
```bash
npm start

```
